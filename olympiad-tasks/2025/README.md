# IOAI 2025 Tasks

IOAI 2025 was held in Beijing, China. The official archive contains an at-home round, six individual contest tasks, GAITE materials, translations, and a team challenge.

## Individual Contest

| Task | Main area | Official materials |
|---|---|---|
| Radar | Radar/signal-related machine learning | [Task 1](https://github.com/IOAI-official/IOAI-2025/tree/main/Individual-Contest) |
| Chicken Counting | Computer vision and counting | [Task 2](https://github.com/IOAI-official/IOAI-2025/tree/main/Individual-Contest) |
| Concepts | Language/semantic concepts | [Task 3](https://github.com/IOAI-official/IOAI-2025/tree/main/Individual-Contest) |
| Restroom Icon Matching | Visual matching | [Task 4](https://github.com/IOAI-official/IOAI-2025/tree/main/Individual-Contest) |
| Antique Painting Authentication | Image analysis/authentication | [Task 5](https://github.com/IOAI-official/IOAI-2025/tree/main/Individual-Contest) |
| Pixel Efficiency | Computer vision/model efficiency | [Task 6](https://github.com/IOAI-official/IOAI-2025/tree/main/Individual-Contest) |
