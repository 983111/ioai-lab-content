# IOAI Past Tasks (2024–2026)

This directory indexes official International Olympiad in Artificial Intelligence task materials by year. It is designed for the IOAI Lab website to load as JSON/Markdown from this repository.

## Years

- [IOAI 2024](./2024/README.md) — scientific round (at-home and on-site) plus practical team challenge.
- [IOAI 2025](./2025/README.md) — at-home round, individual contest, GAITE materials, and team challenge.
- [IOAI 2026](./2026/README.md) — at-home round, individual contest, and GAITE hints.

Each year folder contains:
- `README.md`: student-facing overview and official links.
- `tasks.json`: machine-readable task catalogue for the website.

## Source and attribution policy

The official task statements, datasets, figures, starter code, and reference solutions remain in the official IOAI repositories or official IOAI website archives. This index links to those materials rather than silently duplicating large datasets or changing official statements. Task titles and short summaries are included for navigation; they are not substitutes for the original statements.

Check the licence in each official source before redistributing task files or datasets. Where you create your own explanation, walkthrough, or solution, label it as an IOAI Lab editorial and keep it separate from official content.
