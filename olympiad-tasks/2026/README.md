# IOAI 2026 Tasks

IOAI 2026 took place in Astana, Kazakhstan. The official repository contains three at-home tasks and six on-site Individual Contest tasks. The GAITE track used the same six on-site tasks with additional hints.

## At-Home Round

1. **Operation Night Watch**
2. **Robot Delivery Academy**
3. **The Analytical Language of John Wilkins**

[Open official At-Home Round materials](https://github.com/IOAI-official/IOAI-2026/tree/main/At-Home-Round)

## Individual Contest

| Day | Task | Short description |
|---|---|---|
| Day 1 | Find the Order | Reconstruct the order of speaker turns in shuffled audio dialogue segments. |
| Day 1 | Robot Chasing | Predict robot behaviour from natural-language instructions in grid worlds. |
| Day 1 | Potato | Play a word-guessing game using pairwise semantic-similarity feedback. |
| Day 2 | Double Agent Dilemma | Use differences between two image classifiers to identify informative disagreements. |
| Day 2 | Ghost of the Machine | Detect machine-altered passages in a text archive. |
| Day 2 | IOAI Field | Train a generator from scratch to model the IOAI logo as a spatial function. |
