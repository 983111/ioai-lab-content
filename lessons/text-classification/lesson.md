# Text Classification Baseline

## Overview
Build a text classifier using TF-IDF and logistic regression. The notebook uses a small toy dataset with no external download.

**Time:** 35–50 minutes · **Level:** Intermediate

## Learning objectives
- Convert text into numerical features.
- Explain TF-IDF.
- Train and evaluate a baseline.
- Interpret precision, recall, and a confusion matrix.

## Workflow
Inspect labels, split data, fit TF-IDF inside a pipeline, evaluate, and inspect new predictions.

## Key idea
TF-IDF weights terms by their frequency in a document and rarity across documents. The pipeline learns vocabulary from training text only. The toy dataset demonstrates workflow, not real-world accuracy.

## Exercises
Compare unigrams and bigrams, try Naive Bayes, add labelled examples, and explain duplicate leakage.
